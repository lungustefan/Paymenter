# Filament styles

The stylesheets in this directory are the CSS sources of the [Filament](https://filamentphp.com) packages
(`filament/filament`, `actions`, `forms`, `infolists`, `notifications`, `schemas`, `support`, `tables`,
`widgets`), which are released under the MIT license. They are compiled together with the Tailwind
utilities of the admin panel into the admin theme (`public/build/themes/<theme>/admin.css`), exactly
like the PHP release's Vite build of `resources/css/filament/admin/theme.css`.
